# INSITE(TM) Development Impact Fee Financing Program: the build package

Administered by HGF Management Company | Prepared for Dennis Lanni | July 2026 | Pre-launch

This repository is the complete working package for INSITE, a proposed California program that finances development impact fees for small residential subdivisions (2 to 50 lots) through Mello-Roos special taxes collected on the county tax roll. Every factual claim in these documents traces to a source URL in the Claims Register or is explicitly labeled an inference or a founder estimate.

## How to read this package

Start with `00_PLAN/INSITE_Master_Plan.pdf` (the contract for the build) and `02_PROGRAM/INS-000_INSITE_Primer.pdf` (the plain-language education). The flagship is `02_PROGRAM/INS-008_Program_Whitepaper.pdf`. The evidence discipline lives in `01_EVIDENCE/Claims_Register.md`. The honest self-attack is `08_REDTEAM/Kill_Memo.pdf`. Open questions for the founder are consolidated in `07_BUILDLOG/Build_Log.pdf`, Part 1.

## Standing rules baked into every artifact

Never claim no mechanism exists (SCIP and BOLD are credited by name). The 3:1 value test is law; 4:1 is program policy. School fees are excluded at launch. Rates, costs, and minimums appear only as labeled targets or founder estimates. The pilot is described generically until documents are final. Every handout carries the standard disclaimer.
